# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability, please **do not open a public GitHub issue**.

Instead, report it privately:

- Email: ar.frappe.dev@gmail.com

Please include:

- A description of the issue and potential impact
- Steps to reproduce (proof-of-concept if possible)
- Affected versions/branches (if known)
- Any suggested fix or mitigation

## Supported versions

Security fixes are typically applied to the default branch.

## Disclosure

We aim to respond within a reasonable timeframe and will coordinate a fix and disclosure timeline with the reporter.
